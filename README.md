# dsh-draft-studio

输入框旁的草稿改写按钮：把草稿原位改写成更清晰、更完整的结构化提示词，不自动发送。只适配 DeepSeek Harness 自身——模型、设置、撤销全部走宿主官方接口。

## 1. 它是什么

草稿非空时，发送按钮左侧出现一个按钮。点它，草稿被改写成结构化提示词并**原位替换**，不发送；再点一下还原。

- **撤销**：一键回退，也可以直接 Ctrl+Z（写回是编辑器的一次原生可撤销操作）。
- **上下文可选**：开启后把当前会话最近的发言作为*数据*（不是指令）一并发给模型，用于消解「刚才说的」「改一下」这类指代。
- **模型两档**：跟随会话（provider、模型、思考强度全部跟随）或固定模型（从目录选一个，可单独指定该模型声明的思考强度）。
- **四套预设**：通用 / 编程 / 写作 / 翻译，每套一份完整、可编辑的提示词。

## 2. 安装 / 卸载

**安装**：DSH 插件页 → 添加插件 → 本地目录，指向本文件夹。

**卸载**：插件页 → 本插件 → 移除。只想暂时停用就用开关，不必卸载。

link 安装下改代码即时生效；`git commit` 留版本。

## 3. 用

### 3.1 按钮

四态循环：**空闲**（点击开始）→ **运行中**（显示已用秒数，点击取消）→ **可回退**（结果已写回，点击还原）→ **失败**（tooltip 给具体原因，点击重试）。

等待期间可以继续编辑草稿、切到别的会话，甚至发送草稿：

- 结果回来时若草稿已不是原样，**不会被覆盖**，结果保留待重试；
- 草稿还在的话，点重试会把保留的结果放回*当前*输入框；
- 切换会话不打断运行中的请求，回到该会话能看到真实状态。

### 3.2 设置页

设置 → 草稿工坊：

- **两个开关**：总开关、读取会话上下文。
- **预设下拉**：选中哪套，下方编辑的就是哪套的提示词。
- **提示词编辑**：一份完整的 system prompt；清空并保存 = 恢复内置默认，「恢复默认」按钮同效。
- **模型来源**：分段切换「跟随会话 / 固定模型」。固定时展开两个下拉——模型（来自共享目录）与思考强度（只列该模型声明的档位；「模型默认」= 不发送）。
- **保存条**：左侧显示未保存项数，右侧放弃 / 保存。

## 4. 配置项

15 个字段，可在 `cordis.patch.yml` 的 `config:` 块或设置页改。改完即时生效——每次请求重读配置。

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `preset` | `general` | 当前预设（general/code/writing/translation） |
| `promptGeneral` / `promptCode` / `promptWriting` / `promptTranslation` | 内置文本 | 每套预设的完整提示词 |
| `contextEnabled` | `true` | 读取会话上下文 |
| `modelMode` | `follow` | `follow` 或 `fixed` |
| `provider` / `model` | 空 | 固定模型的 provider 与模型 id |
| `reasoningEffort` | 空（模型默认） | 固定模型的思考强度 |
| `maxOutputTokens` | `2000` | 单次输出上限 |
| `timeoutMs` | `180000` | 单次请求截止时间 |
| `contextMaxMessages` / `contextMaxChars` | `8` / `4000` | 上下文条数与字符预算 |

## 5. 边界与已知限制

- **命令芯片**：草稿里含 `/` 命令标签（从 `/` 菜单认领的那种）时，结果可能无法自动写回——宿主未发布这类标签的坐标换算数据。此时原稿不丢、结果保留可重试；删掉该标签再优化即可。`@` 引用标签不受影响。
- 手打的 `/xxx` 文本不是芯片，按普通文字处理。
- **思考强度被拒**：固定模型不支持所选档位时，自动按该模型默认强度重试——结果正常，只是强度覆盖失效。
- **耗时**取决于模型与强度：跟随模式会继承会话强度（会话是 Max 就跑满 Max）。要快，固定模型里选低强度或轻量模型。
- 超时 180 秒；超时后草稿不变，可重试。
- **不做**：自动发送、多轮改写、模板库、历史记录、重启后的落盘上下文回放。

## 6. 源码地图

纯 JavaScript，无构建。验证方式：`node --check` + 真机操作（无 lint、无类型检查、无测试套件）。

| 文件 | 职责 |
|---|---|
| `index.js` | 宿主半包：Config schema（15 字段全 volatile）、三级模型路由、上下文装配、`generate`（`finish.kind` 分派 + 预算翻倍重试 + 强度回退）、`POST /dsh-draft-studio/refine`（loopback 栅栏 + 1 MiB 上限 + 超时） |
| `client.js` | 浏览器半包：按钮四态、`insertText` 写回（draftRev 守卫 + 芯片坐标折算）、一键回退、模块级任务注册表、设置页、中英文案 |
| `cordis.patch.yml` | 装载声明（一行 insert，entry id 全局唯一） |
| `package.json` | `dsh.bundle.patch` + `dsh.client.platform: web`；`@deepseek-ai/schemastery` 声明为 `peerDependencies`，由宿主运行时提供 |
| `locale/*.json` | 市场卡片元数据 |

改造入口：提示词文本看 `index.js` 的 `PROMPT_BASE` / `PRESETS`；交互看 `client.js` 的 `RefineControl`；模型路由看 `index.js` 的 `resolveRoute`；设置页控件看 `client.js` 的 `SettingsSection`。
