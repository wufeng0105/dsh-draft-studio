# dsh-draft-studio

输入框旁的提示词优化按钮：把草稿改写成更清晰、更完整的提示词，原位写回，不自动发送。只适配 DeepSeek Harness 自身——模型、设置、撤销全部走宿主官方接口。

## 1. 它是什么

- 输入框非空时出现一个按钮，点击后用当前会话的模型把草稿改写为结构化提示词，**原位替换、不自动发送**。
- 带撤销：一键回退到改写前的原文；也可以直接 Ctrl+Z（写回是编辑器原生可撤销操作）。
- 上下文可选：开启后把当前会话最近的发言作为**数据**（不是指令）一并发给模型，用于消解「刚才说的」「改一下」这类指代。
- 模型来源两档：**跟随会话**（provider、模型、思考强度全部跟随当前会话）或**固定模型**（在目录里选一个，可单选该模型的思考强度）。
- 4 套预设（通用 / 编程 / 写作 / 翻译），每套一份完整可编辑的提示词。

## 2. 安装 / 卸载

- **安装**：DSH Web 界面 → 插件页 → 添加插件 → 本地目录，指向本文件夹；或 `plugin_manager` 的 `install_bundle`，target 填本文件夹绝对路径。
- **卸载**：插件页 → 本插件 → 移除。也可以只停用：卸载保留文件，停用只是不加载。
- 本目录已 `git init`，改代码后 `git commit` 即可留版本；link 安装方式下改动即时生效（宿主 HMR 重组或刷新页面）。

## 3. 用

### 3.1 按钮

- 草稿非空时出现在发送按钮左侧；空草稿不出现。
- 四态：**空闲**（点击开始）→ **运行中**（显示已用秒数，点击取消）→ **可回退**（结果已写回，点击还原）→ **失败**（tooltip 显示具体原因，点击重试）。
- 等待期间可以继续编辑草稿、切到别的会话、甚至发送草稿——结果回来时若草稿已不是原样，不会被覆盖；草稿还在的话，点重试会把保留的结果放回**当前**输入框。
- 切换会话不打断运行中的请求；回到该会话能看到真实状态。

### 3.2 设置页

设置 → 提示词优化：

- **预设切换**：4 个分段按钮，切换后下方编辑的是对应预设的提示词；「恢复默认」回插件内置文本。
- **提示词编辑**：每套一份**完整**的提示词（就是发给模型的 system）；清空并保存 = 恢复内置默认。
- **上下文开关**：默认开。开启后每次优化会读取当前会话最近发言（8 条 / 4000 字符内）。
- **模型来源**：跟随会话（含思考强度一起跟随）；或固定模型——从目录选模型后可再选**思考强度**（只列出该模型声明的档位；「模型默认」= 不发送）。

## 4. 配置项

全部 15 个字段可在本插件目录的 `cordis.patch.yml`（`config:` 块）或设置页改；除标注外设置页可见。

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `preset` | `general` | 当前预设（general/code/writing/translation） |
| `promptGeneral` / `promptCode` / `promptWriting` / `promptTranslation` | 内置文本 | 每套预设的完整提示词 |
| `contextEnabled` | `true` | 上下文开关 |
| `modelMode` | `follow` | `follow` 或 `fixed` |
| `provider` / `model` | 空 | 固定模型的 provider 与模型 id |
| `reasoningEffort` | 空（模型默认） | 固定模型的思考强度；模型不支持时自动按默认强度重试 |
| `maxOutputTokens`（隐藏） | `2000` | 单次输出上限 |
| `timeoutMs`（隐藏） | `180000` | 单次请求截止时间 |
| `contextMaxMessages` / `contextMaxChars`（隐藏） | `8` / `4000` | 上下文条数与字符预算 |

改 `cordis.patch.yml` 即时生效（每次请求重读配置）；设置页保存也即时生效。

## 5. 边界与已知限制

- **命令芯片**：草稿里含 `/` 命令标签（从 `/` 菜单认领的那种）时，结果可能无法自动写回——宿主未发布这类标签的坐标换算数据。此时原稿不丢、结果保留可重试；删掉该标签再优化即可。`@` 引用标签**不受影响**。
- **手打的 `/xxx` 文本不是芯片**，按普通文字处理，无影响。
- **思考强度被拒**：固定模型不支持所选档位时，自动按该模型默认强度重试（结果正常，只是强度覆盖失效）。
- **改写耗时**取决于模型与思考强度：跟随模式会继承会话强度（会话是 Max 就跑满 Max）；要快，固定模型里选低强度或轻量模型。
- 超时 180 秒；超时后草稿不变，可重试。
- **不做**：自动发送、多轮改写、模板库、历史记录、重启后的落盘上下文回放。

## 6. 源码地图

纯 JavaScript，无构建；验证方式为 `node --check` + 真机操作（无 lint / 类型检查 / 测试套件）。

| 文件 | 职责 |
|---|---|
| `index.js` | 宿主半包：Config schema（15 字段全 volatile）、三级模型路由（固定 → 会话投影 → 部署默认）、上下文装配（deriveMessages → 裁剪 → JSON）、`generate`（finish.kind 分派 + 预算翻倍重试 + 强度回退）、`POST /dsh-draft-studio/refine`（loopback 栅栏 + 1 MiB 上限 + 超时） |
| `client.js` | 浏览器半包：按钮四态、`insertText` 写回（draftRev 守卫 + 芯片坐标折算）、一键回退、模块级任务注册表（切会话不中断）、设置页（configForms 读写 + modelCatalog + 思考强度菜单）、中英文案 |
| `cordis.patch.yml` | 插件装载声明（一行 insert，entry id 全局唯一） |
| `package.json` | `dsh.bundle.patch` + `dsh.client.platform: web`；依赖仅 `@deepseek-ai/schemastery` |
| `locale/*.json` | 中英文案（插件同时内置双字典，此目录为元数据） |

改造入口提示：改提示词文本看 `index.js` 的 `PROMPT_BASE` / `PRESETS`；改交互看 `client.js` 的 `RefineControl`；改模型路由看 `index.js` 的 `resolveRoute`；设置页控件在 `client.js` 的 `SettingsSection`。
